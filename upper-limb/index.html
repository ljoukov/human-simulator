Model sources & credits

The 3D model adapts the Open3D Project’s right upper limb, which builds on BodyParts3D and Z-Anatomy. This version selects and recolors structures and adds an elbow rig. The adapted mesh is available under CC BY-SA 4.0. Open3D Project · Contributors · Original model archive

Biceps path length and moment arm come from the generic OpenSim Arm26 model, sampled with the shoulder at 0°. The OpenSim Development Team adapted the model from Kate Holzbaur’s upper-extremity model. Arm26 reference model · CC BY 3.0
